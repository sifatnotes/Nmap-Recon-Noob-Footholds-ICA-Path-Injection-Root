## Learning Path

A practical progression through these **cybersecurity labs**:

1. Begin with **Noobs First Steps** to establish basic CTF methodology.
2. Study **Scan Storm: Nmap Recon Essentials** for network reconnaissance.
3. Continue with the Noob foothold challenges.
4. Explore ICA access and project-investigation labs.
5. Practice identifying information leaks and breach indicators.
6. Move into the ICA escalation challenges.
7. Finish with the path-injection and path-escalation labs.

## How to Use the Labs

Use these labs only in authorized environments such as CTF platforms, personal virtual machines, or intentionally vulnerable training systems.

For each challenge:

1. Read the objective and identify the authorized scope.
2. Perform reconnaissance appropriate to the lab.
3. Identify exposed services, applications, files, or access paths.
4. Analyze discovered weaknesses and their security impact.
5. Document the investigation and escalation path.
6. Consider defensive controls that could prevent the issue.
7. Record lessons learned for future CTF and penetration-testing exercises.

Never test these techniques against systems without explicit authorization.
